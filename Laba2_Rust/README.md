# Лабораторная работа № 2 — Rust

Семь заданий, реализованных на собственных структурах данных. В `main.rs` подключены только присутствующие модули; удалённые файлы `avl_tree.rs` и `queue.rs` не требуются.

## Сборка

```bash
rustc --edition=2021 -O main.rs -o dbms
./dbms
```

## Тесты

```bash
rustc --edition=2021 --test main.rs -o tests
./tests
```

## Задание 6

В главном меню выбрать `6`, затем `5`. Эксперимент использует 23 ячейки, 6, 11, 17 и 21 пару, 3 повторения. Для линейного пробирования и двойного хеширования замеряются время и число проверок при вставке, успешном и безуспешном поиске.

В таблицах отдельно хранятся ключи, значения и состояния ячеек с помощью собственных `Array`. Фильтр Блума тоже использует собственный массив. Для честного измерения безуспешного поиска применяется `contains_without_bloom`.

`Vec`, `VecDeque`, `HashMap`, `HashSet`, `BTreeMap` и готовые контейнеры для реализации заданий не используются.
